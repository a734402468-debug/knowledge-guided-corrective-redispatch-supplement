# Supplementary Data for Knowledge-Guided Corrective Redispatch

This repository provides supplementary data, prompt materials, checker rules, and experiment results for the manuscript:

**Knowledge-Guided Corrective Redispatch through Checked LLM Interpretation and Sensitivity-Aware Optimization**

The repository is intended to support the reproducibility and auditability of the reported case studies. It provides cleaned numerical data and scenario-level results rather than the full DIgSILENT PowerFactory project files.

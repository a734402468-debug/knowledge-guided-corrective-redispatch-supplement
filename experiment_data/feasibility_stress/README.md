# Hard-Rule Feasibility-Stress Study

This folder records the frozen aggregate convergence counts reported in Figure 5 and Section 4.3.

Both methods were evaluated on the same 64-case feasibility-stress set with the same AC-validation criterion, monitored thermal limits, and 12-iteration cap. The hard-constrained baseline removes all Level 1 redispatch directions, whereas the proposed method retains them as penalized backup candidates.

`aggregate_convergence_summary.csv` contains the reported counts and rates. The original per-case dispatch archive for this study is not included; this folder is therefore an aggregate result record and is not presented as scenario-level raw data.

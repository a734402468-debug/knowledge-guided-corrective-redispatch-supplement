# Revision Analyses

This folder contains compact evidence added in response to the major-revision comments. It supplements the archived experiment data without representing a new benchmark.

## Contents

- `parameter_sensitivity/`: separation-factor and PTDF-threshold analyses supporting Table 2.
- `first_to_final/`: first-round versus final AC-valid redispatch comparison.
- `representative_cases/`: two fixed-topology examples illustrating avoidance and backup use of lower-priority resources.
- `common_subset/`: case-matched priority metrics supporting Table 6.
- `runtime/`: prototype timing breakdown supporting Table 7.

Each folder documents the relevant denominator and interpretation boundary. These summaries should be read together with the definitions and limitations in the revised manuscript.

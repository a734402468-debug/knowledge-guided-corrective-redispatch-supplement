# First-Round versus Final AC-Valid Redispatch

This analysis covers the 88 fixed-topology cases in which the proposed method obtained an AC-valid final dispatch.

- active-priority-tier set unchanged: 68/88 (77.3%);
- binary Level 1/Level 2 participation status unchanged: 75/88 (85.2%);
- median absolute first-to-final changes in EZAD and Level 1+Level 2 activation: 0 percentage points;
- all 13 observed binary status changes were inactive-to-active, indicating the introduction of lower-priority backup during AC refinement.

The analysis does not claim that first-round composition is invariant. The full compact summary and the per-case audit table are provided in this folder.

# Parameter-Sensitivity Analyses

`eta_sensitivity_summary.csv` reports the independent controlled separation-factor study over eta = 1.01, 1.05, 1.10, 1.25, and 1.50. The controlled run uses a frozen label realization that differs from the main evaluation; it is not intended to reproduce the main 88/100 count exactly.

`ptdf_threshold_summary.csv` is a retrospective audit of the frozen reference PTDF matrices for the 88 originally AC-valid proposed-method cases. It evaluates the coverage-conservativeness effect of the PTDF threshold and does not rerun the LLM, corrective OPF, or SLP-AC validation.
